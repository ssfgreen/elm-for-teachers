# Dyslexia-friendly documents

Change how the document reads, not what it teaches: keep the learning goal, the key vocabulary and the thinking the task asks for. A dyslexia-friendly version is not an easier task unless the teacher asks for one.

## Wording

- Short sentences, one idea each. Active voice ("Underline the simile", not "The simile should be underlined").
- Everyday words where they mean the same; keep subject terms (simile, metaphor) and explain them the first time.
- Say what to do before what to do it with: "Underline the simile in each sentence." then the sentences.
- No double negatives. No idioms in instructions.
- Number the steps of a task with several steps, one step a line.

## Layout

- Break long paragraphs into short ones or bullet points. Leave each question its own line.
- Use headings so the page can be scanned.
- For emphasis use **bold**. Do not use italics, underlining (except for an underlining task itself) or BLOCK CAPITALS.
- Keep text left-aligned; never put instructions inside a table cell unless it is a grid task.
- Give answer spaces room: a line of dots (……) the length of the expected answer, not a short blank.

## Support

- Offer a short word bank or glossary for key vocabulary, at the top or beside the task, when there is new or technical language.
- Give one worked example before the first question.
- Keep the number of questions the same unless the teacher asks; if the page is long, split it into parts with headings.

Font sizes are outside what you can change. Suggest a font or page colour (set_style) only when the teacher asks for one.

When you review a document rather than rewrite it, check it against checklist.md (read_skill with file "checklist.md") and comment on what to change.
