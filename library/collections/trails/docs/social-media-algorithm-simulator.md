# Social Media Algorithm Simulator

In this activity, students think about what best makes a social media algorithm. What can we consider when deciding which posts best suit a user? How does placing different value on each of these impact which posts are shown to the user?

The lesson pack comes with slides and a selection of post cards, and a worksheet. There is also an online tool that can help with the calculation of the post scores for each post.

[Social Media Simulator – WHOLE ACTIVITY](https://trails.scot/wp-content/uploads/2026/08/Social-Media-Simulator.zip)

An online companion calculator was developed. [Click here](https://tonisewell.github.io/social-media-calculator/).

This activity was created as a part of our [Core AI Literacy Lesson “How AI Influences you”](https://trails.scot/resource/how-ai-influences-you/).
