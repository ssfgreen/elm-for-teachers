# AI 02 – AI Image Bias Reflection – worksheet

From the TRAILS resource [Seeing is Not Always Believing](https://trails.scot/resource/seeing-is-not-always-believing/) (DOCX).

AI Image Bias Reflection

Instructions: How to Use the Prompt Reflection Table

Work with a partner or small group.

Write two prompts to create AI images:

One neutral prompt (e.g. “a group of friends”)

One inclusive prompt (e.g. “a group of friends with different skin tones and body types”)

Use AI to generate an image for each prompt.

Look closely at both images. Ask yourselves:

What changed?

Who is shown?

Is anyone missing?

Fill in the table together:

Write your two prompts in the first two columns.

Describe the differences you notice in the images.

Decide which image feels more fair or realistic — explain why.

Think about how you could improve the prompt next time.

Use the Bias Visual Scale to help you decide how fair each image is.

Bias Visual Scale

Use this scale to help you think about whether the image you created is fair or biased.

😊

Fair and Inclusive

Shows a variety of people - skin tones, body types, genders, abilities, etc.

😐

Mixed / Could Be Better

Some diversity but missing a few groups or repeats common stereotypes.

☹️

Unfair / Stereotyped

Reinforces stereotypes, lacks variety or shows only one kind of person.
