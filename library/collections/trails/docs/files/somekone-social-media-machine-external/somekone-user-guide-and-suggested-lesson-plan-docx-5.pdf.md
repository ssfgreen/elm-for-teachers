## Page 1

Somekone:
User Guide & Lesson Plan
Teacher note — It is possible to run a ‘demo’ session to familiarise yourself with the software before
teaching pupils .
Prior learning
Pupils should be familiar with the concepts of in fl uence, recommender systems, bias , and how social
media apps optimise feeds to appeal to you .
Learning objective & success criteria
Learning objective: Understand how social media feeds work .
Success criteria (students can):
Identify the different types of data that social media apps collect.
Explain how data is used to create a pro fi le for you and make recommendations to you .
Give your opinion on how your data is used, and explain your thinking.
Introduction (starter)
Task: Revisit prior learning using the key words slide, focusing on the concepts of in fl uence,
recommender systems and optimising social media feeds .
Discussion task
What is the purpose of social media?
How are social media feeds “ optimised ” ?
Key points to share with learners before beginning
This is a ‘sandbox’ version of a social media app.
All the images you will see are appropriate for your age and stage.
You will be able to like images, follow the poster, share content with others on the app and comment
on pictures.
None of your data is kept or shared outside of the app.

Somekone user guide (teacher steps)
Use the steps below to set up the session, let pupils generate interaction data, then guide discussion
using the built-in views (data, pro fi ling, similarity, recommendation, fi nish).
1. Go to somekone.gen-ai. fi and click ‘create new session’.

2. Select ‘core concepts’ .
3. Users can now join the session, either by scanning the QR code or going to the web address and
typing in the displayed code. Throughout the session, you can click on the ‘connect’ option, then
click on the QR code displayed at the bottom left of the screen and it will show the code.
3: Teacher view of the Somekone in-session menu. 4: learner view of the username page
4. Pupils will see a screen prompting them to enter a username. Pro fi le pictures are randomly
generated.
Pupils will now see a feed of various images. Give them a few minutes to like, comment, share and follow
the images that appeal to them. This will build a robust data set for the next steps.
