## Page 1

Midge – Biting or Non-Biting?
In this project you will make a Scratch project that learns to classify
images of midges as either biting or non-biting .
You will train the computer to be able to recognise biting and non-
biting midges and your project will report how confident the model is
in its classification.

## Page 6

18.
What have you done so far?
You’ve started to train a computer to recognise pictures of
biting and non-biting midges. Instead of writing rules to do this,
you are doing it by collecting examples. These examples are
being used to train a machine learning “ model ” .
This is called “supervised learning” because of the way you are
supervising the computer’s training.
The computer will learn from patterns in the example images
that you have uploaded, such as the features and colour (black
or white). These will be used to be able to recognise new midge
images.
