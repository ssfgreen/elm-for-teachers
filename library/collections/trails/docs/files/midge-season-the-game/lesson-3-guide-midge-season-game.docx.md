# Lesson 3 Guide – Midge Season Game

From the TRAILS resource [Midge Season: The Game](https://trails.scot/resource/midge-season-the-game/) (DOCX).

Lesson Title

Lesson 3 – Midge Season Game – Train and Test an AI Model to Recognise Sounds

Introduction

In this lesson, students will train a machine learning model to recognise voice commands ‘up’, ‘down’, ‘left’, and ‘right’, and use them to control a biting midge in a fun game.

Delivery over multiple periods of learning may be advisable depending on prior learning.

This lesson is designed for Computing Science students, S4 to S6 to support learning and teaching of AI concepts and practical skills for learners undertaking SQA Artificial Intelligence Unit(s) (Level 4 - J8E0 44, Level 5 - J8E0 45, Level 6 - J8E0 46).

Learning Intentions/Success Criteria

Learning Intentions

Understand Machine Learning Basics:

Students will learn how machine learning can be applied to recognise voice commands.

Set Up a Machine Learning Project:

Students will learn how to set up a machine learning project using the provided tools and resources.

Collect and Label Data:

Students will understand the importance of collecting and labelling data accurately for training a machine learning model.

Train a Machine Learning Model:

Students will learn the steps involved in training a machine learning model to recognise specific voice commands.

Test and Evaluate the Model:

Students will learn how to test the trained model and evaluate its performance in recognising voice commands.

Integrate Machine Learning with Scratch:

Students will learn how to integrate the trained machine learning model with a Scratch project to control game elements using voice commands.

Enhance the Game with Additional Features:

Students will explore ways to enhance the game by adding new features, such as extra points for collecting items or creating a two-player mode.

Success Criteria

Accurate Data Collection:

Students collect and label at least 8 examples of background noise and each voice command ('up', 'down', 'left', 'right').

Effective Model Training:

Students successfully train the machine learning model using the collected data.

Model Recognition Accuracy:

The trained model accurately recognises the voice commands during testing.

Integration with Scratch:

Students integrate the machine learning model with the Scratch project and control the game elements using voice commands.

Game Functionality:

The game functions correctly with voice commands, and students can move the midge in the expected directions.

Creative Enhancements:

Students add creative enhancements to the game, such as random items for extra points or a two-player mode and test their functionality.
