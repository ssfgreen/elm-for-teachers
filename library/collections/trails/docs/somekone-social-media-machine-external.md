# Somekone – Social Media Machine (External)

Somekone is a browser-based social media simulator that allows learners to explore and understand how social media platforms collect data, build user profiles, and recommend content. It visually resembles the feed of familiar social media image platforms, while making visible the processes that usually remain hidden.

It’s a great tool to use with a class, to help them understand really how social media algorithms work behind the scenes.

[Link to the online tool.](https://gen-ai.fi/en/tools/somekone)

This tool has been created and developed by our friends at [Generation AI](https://gen-ai.fi/en) in Finland.

This tool is recommended as part of our core AI literacy lesson “[How AI influences you](https://trails.scot/resource/how-ai-influences-you/)“.

One of our Teacher Associates, Samantha Hatton, has created a guide and lesson plan for using this resource with your class. You can download that here:
