# Pedagogy library (draft)

The first plugin. It holds one collection, `pedagogy-scotland`: principles, activities, subject
pedagogies, adaptations, format rules, cautions and curriculum links for P7 Literacy and English
and S1 history, each split into claims backed by passages from named sources. Every entry is a
draft that no teacher or specialist has reviewed yet.

The assistant uses it in class and year group chats, through the tools `entries`, `entry`,
`claims` and `facets`. A teacher can hide entries, favour entries, and ask for entries rated at
least a given level of evidence (applied from a later version of the runner).

Reuse is `use_only`: each source keeps its own licence, and most are not yet confirmed.

The collection's files are still in `library/collections/pedagogy-scotland`; the library places
them at `collections/pedagogy-scotland` in this plugin when it loads it.
