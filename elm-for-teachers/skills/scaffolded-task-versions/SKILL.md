# Scaffolded task versions

## What this skill does

Turns one task into a small set of versions that differ in the **amount and type of support**, never in the **question, content or success criteria**. Pairs the set with a plan for removing support over time.

## Invariants

1. One objective, one set of success criteria, stated at the top of every version.
2. Versions are labelled by support ("full model", "partial frame", "prompts only"), never by attainment ("lower", "middle", "higher") or by group name ("SEN group", "bottom set").
3. Every version contains every key concept and key term in the source task.
4. A fading plan is always included.
5. No identifiable pupil data.
6. If the request names fixed-ability groups, comply with the support-level version and add a short, cited note explaining why labels were changed. Do not lecture; one paragraph.

## Inputs

- The task (question, success criteria, any stimulus material).
- The learning objective (ask if missing).
- Phase and subject.
- Optional: the barriers the teacher is planning for (e.g. "retaining multi-step instructions", "writing stamina", "vocabulary"). Ask for barriers, not diagnoses.

## Steps

1. **Identify the core.** Write down the objective, the success criteria, the key concepts and the key terms. These are the invariant set.
2. **Produce three versions** using the same question and the same success criteria:
   - **Version A, full model:** a complete worked example or model answer for a parallel case (not the actual question), followed by the task with the structure made visible (paragraph headings, numbered steps, a completed first step).
   - **Version B, partial frame:** sentence starters, a writing frame, or a worked example with missing steps (faded example). Key-term box present.
   - **Version C, prompts only:** the task as set, with a short checklist of the success criteria and one or two metacognitive prompts ("What is the question asking? What will I do first?").
3. **Add the fading plan:** when and how a pupil moves from A to B to C within the unit (e.g. "A for the first two tasks, B when the first step is secure, C by the end-of-unit task"). Fading is the point; a version without a fading plan is a tier.
4. **Add teacher notes:** what to look for to move a pupil along; which parts of the model to remove first; a reminder that groups are temporary and based on current mastery of this objective.
5. **Run the checks.**

## Checks

- [ ] All three versions contain the same question and success criteria (checker diffs them).
- [ ] All key terms and concepts present in all versions.
- [ ] Labels are by support level only.
- [ ] Fading plan present.
- [ ] Worked examples are subject-accurate. Flag any step the agent is not confident about.
- [ ] No reduction in the cognitive demand of the final outcome.

## Output

1. Three versions, labelled A, B, C by support level.
2. Fading plan.
3. Teacher notes.
4. Change log and sources.

## When to refuse or redirect

- "Make a different, easier task for the SEN group": explain that changing the objective is a decision for the teacher with the SENCo or ASL lead, offer version A, and note the CCF/ECF warning about artificially distinct tasks and lower expectations.
- "Put these pupils in the low group": decline allocation; refer to the EEF setting and streaming evidence (worse outcomes for low attainers, on average); offer the fading plan as the grouping mechanism.
- Learning-styles requests: see `negative_evidence_register.md`.

## Sources

- EEF, Special Educational Needs in Mainstream Schools: scaffolding, explicit instruction, flexible grouping ("temporary groups based on current level of mastery").
- EEF, Teaching and Learning Toolkit: setting and streaming (0 months on average; worse for low attainers); within-class attainment grouping (earlier analysis, +3 months).
- DfE, ITT Core Content Framework / Early Career Framework: adaptive teaching is less valuable if it creates distinct tasks or lower expectations for particular pupils.
- Deunk et al. (2018), Educational Research Review: homogeneous ability grouping, small negative effect for low-ability pupils.
- Smale-Jacobse et al. (2019), Frontiers in Psychology: differentiated instruction in secondary, positive but thin evidence.
- Sweller, van Merriënboer and Paas on worked examples and the expertise reversal effect (fade support as expertise grows).
