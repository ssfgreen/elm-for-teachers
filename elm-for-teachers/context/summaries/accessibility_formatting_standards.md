# Accessibility Formatting Standards (data context)

**Type:** Reference document for agentic systems. Rule-based; every rule is checkable. Read for any task that reformats, enlarges, captions or re-lays-out a resource.
**Version:** 0.1, 16 October 2026. Re-verify against the current BDA, UKAAF and RNIB publications before each pilot phase.

## 1. Dyslexia-friendly print and screen (British Dyslexia Association Style Guide 2023)

| Rule | Value | Checkable as |
|---|---|---|
| Font family | Sans-serif: Arial, Verdana, Calibri, Tahoma, Century Gothic, Trebuchet | font-family in output |
| Body size | 12 to 14 pt minimum; larger for younger pupils | font-size |
| Line spacing | 1.5 | line-height |
| Inter-word spacing | At least 3.5 times inter-letter spacing | word-spacing |
| Headings | At least 20% larger than body; bold | heading size ratio |
| Emphasis | Bold only | absence of italic, underline, all-caps runs |
| Alignment | Left aligned, ragged right; no justification; no columns | text-align |
| Background | Cream or soft pastel; dark text; avoid pure black on pure white | background colour |
| Paragraphs | Short; one idea; sub-headings; bullets and numbers for sequences | paragraph length distribution |
| Print | Matt paper; avoid glossy | note to teacher |
| Note | No consistent reading advantage for specialised "dyslexia fonts" (Dyslexia Scotland 2025) | do not prescribe |

## 2. Clear print and large print (UKAAF G003, 2024; RNIB)

| Format | Minimum size | Notes |
|---|---|---|
| Clear print | 12 pt, 14 pt preferred | For general accessibility |
| Large print | 16 pt minimum; 18 pt recommended | Sans-serif; bold where the reader needs it |
| Modified large print (MLP), KS1 | Arial 18 pt bold | RNIB exam guidance |
| Modified large print (MLP), KS2 and above | Arial 24 pt bold | RNIB exam guidance |
| Rebuild, do not enlarge | MLP must be rebuilt digitally, not photocopied up | Photocopy enlargement degrades contrast and layout |
| Diagrams | Simplify; remove non-essential detail; increase line weight; label clearly; describe in text | Flag for QTVI check |
| Layout | One item per page where needed; consistent position of page numbers and instructions | |
| Contrast | High contrast; avoid text over images | |

## 3. Deaf and hearing-impaired access (NDCS; DfE Building Bulletin 93)

| Rule | Value |
|---|---|
| Video | Accurate captions or subtitles on all video; transcript provided |
| Audio | Transcript and key-vocabulary sheet |
| Seating | Within 1 to 3 metres of the speaker, with a clear view of the speaker's face |
| Radio aids | Transmitter passed to each speaker in group work |
| Acoustics | BB93: reverberation time 0.4 s or less in rooms designed for hearing-impaired pupils; reduce background noise |
| Visual supports | Written agenda, key words on the board, visual instructions |

## 4. Digital resources (WCAG 2.2 AA, summarised)

- Text alternatives for all images and diagrams.
- Contrast ratio at least 4.5:1 for body text.
- Logical heading structure (H1, H2, H3) for screen readers and text-to-speech.
- No information conveyed by colour alone.
- Resizable text without loss of content.
- Keyboard-operable interactive elements.

## 5. Text-to-speech readiness

- Plain headings, no text embedded in images.
- Alt text for diagrams that states what the diagram shows, not that it is a diagram.
- Avoid decorative characters and symbols that are read aloud oddly.
- Numbered steps rather than bullets where order matters.
